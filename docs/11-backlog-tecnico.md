# Backlog Tecnico Priorizado

## P0: Fundacion

Estas tareas deben completarse antes de usar datos reales.

- Crear repositorio Git.
- Corregir estructura HTML actual.
- Separar `index.html`, `styles.css`, `app.js` y `data.js`.
- Documentar como abrir la maqueta.
- Crear base de proyecto web.
- Definir stack final.
- Configurar lint/format.
- Crear `.gitignore`.

## P1: Datos reales minimos

- Crear base de datos.
- Crear tablas iniciales.
- Crear API de arboles.
- Crear API de zonas y especies.
- Crear panel privado basico.
- Crear mapa publico basico.
- Calcular conteos desde base de datos.

## P2: Captura de campo

- Crear vista movil.
- Capturar GPS.
- Capturar precision del GPS.
- Tomar o subir foto.
- Crear registro pendiente.
- Revisar registro desde panel administrador.
- Aprobar o rechazar registro.

## P3: QR

- Generar token publico por arbol.
- Crear URL publica por arbol.
- Generar imagen QR.
- Crear formato imprimible.
- Probar escaneo desde movil.

## P4: IA asistida

- Definir proveedor de IA.
- Crear endpoint backend de analisis.
- Guardar resultados en tabla `ai_analyses`.
- Mostrar confianza e incertidumbre.
- Crear pantalla de revision humana.
- Comparar estimacion IA contra medicion manual.

## P5: Calidad y operacion

- Pruebas unitarias.
- Pruebas de API.
- Pruebas e2e de flujo principal.
- Backups.
- Logs.
- Monitoreo de errores.
- Politica de privacidad.
- Manual de operacion.

## Deuda que no debe ignorarse

- Responsive movil real.
- Accesibilidad.
- Sanitizacion de datos.
- Proteccion contra XSS.
- Control de permisos en backend.
- Manejo de imagenes pesadas.
- Costos de IA y almacenamiento.
- Consentimiento para fotos.
